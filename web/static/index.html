本地编译与默认产物设置 (可手动输入路径，或点击右侧按钮直接选择本地目录/文件)

        

          

            
            

              
              
            

            
执行本地编译命令时的工作目录，支持手动填写或点击选择

          

          

            
            

              
              
            

            
可填相对源码目录的路径或绝对路径；免编译模式下也可直接读取此文件上传

          

        

        

          
          
          
在本地电脑执行的编译命令，编译完成后自动提取上述产物经 SFTP 上传至部署服务器

        

      


      
      

        

          
服务器目录配置 (多服务共享 K8s YAML 目录 + 独立 YAML 文件名 & 独立构建目录)

          
        

        

          

            
            
            
每个服务独立存放上传的产物包

          

          

            
            
            
每个服务各自独立的 Dockerfile 构建上下文目录

          

        

        

          

            
            
            
所有服务的 YAML 统一存放在此公共目录下

          

          

            
            
            
发布时系统会自动修改该 YAML 文件中的 image 为新版本并持久化保存

          

        

      


      
      

        
        
        
支持变量: {{.BuildDir}} (独立构建目录), {{.Image}} (该服务镜像名), {{.Tag}} (发布版本号)

      

      

        
        
        
💡 镜像在服务器本地构建完成后已存在于 Docker 缓存中，直接部署无需 push，保持留空即可！
